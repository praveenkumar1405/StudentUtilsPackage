
# Student Utils Package

A simple reusable Python package developed for the Free Open Source Software assignment.

## Features
- Calculate task completion percentage.
- Format task descriptions.
- Reuse functions in other Python programs.

## Installation
Download or clone this repository using Git.

## Usage

```python
from student_utils import calculate_completion, format_task

print(format_task("Complete DBMS assignment", "DBMS"))
print(calculate_completion(3, 5))
```

## Output

```text
Complete DBMS assignment - Subject: DBMS
60.0
```
